# 個人ホームページ(日本語・英語対応)

研究者向けテンプレート [Scholar-Lite](https://github.com/fjd2004711/scholar-lite)(MIT ライセンス)をもとにした、日本語・英語の2言語に対応した個人ページです。
内容の更新は、次の **2つのファイルと写真** だけで行えます。

| 変えたいもの | 編集するファイル |
|---|---|
| 名前・所属・自己紹介・学歴・受賞歴・連絡先 | `src/data/profile.ts` |
| 論文・学会発表(業績) | `citations.bib` |
| プロフィール写真 | `src/assets/` の画像 |
| トップページの背景写真 | `src/assets/hero-real.jpg` |

デザインやプログラムのファイルは、触らなくて構いません。

---

## 1. 内容を更新する(GitHub の画面だけでできます)

1. GitHub でこのリポジトリを開く
2. 編集するファイルをクリックして開く(例: `citations.bib`)
3. 右上の鉛筆アイコン(Edit this file)をクリックして、書き換える
4. 右上の緑のボタン「Commit changes...」→「Commit changes」を押す
5. 1〜2分ほどで、サイトに自動で反映される

> うまく反映されないときは、リポジトリの「Actions」タブを開いてください。
> 最新の実行が赤い × なら、エラーがあります。クリックすると原因が読めます。
> (よくある原因: 引用符 `"` や `'` の閉じ忘れ、行末の `,` の付け忘れ)
> 直前の変更をやり直したいときは、そのファイルの「History」から、前の状態に戻せます。

### プロフィール(`src/data/profile.ts`)

- 日本語は `ja`、英語は `en` に書きます。**両方そろえて**ください。
- 一覧(学歴・受賞歴など)は、上にあるものが先に表示されます。新しいものを上に追加してください。
- 学歴や受賞歴を1件増やすには、既存の1件分(`{` から `},` まで)をコピーして、中身を書き換えます。
- ファイルの最後にある `notice`(練習用の注意書き)は、本番では**削除**してください。

### 業績(`citations.bib`)

- Google Scholar・Zotero・Mendeley から書き出した BibTeX を、そのまま追加できます。
- トップページの「主な業績」に出したいものは、`note={Selected}` を付けます。
- 受賞したものは、`award={賞の名前}` を付けると、金色のラベルが付きます。
- 論文のタイトルを英語、学会名を日本語、のように、日本語と英語は混ぜても構いません。
- ⚠ **ファイルの冒頭の説明文(`%` で始まる行)に、アットマーク記号を書かないでください。** 業績1件の開始と判断され、サイトの作成に失敗します。

### 写真

- プロフィール写真: 正方形に近い画像(縦横 600px 以上)を `src/assets/` に入れ、`src/data/profile.ts` の先頭にある `import photo from '../assets/...'` のファイル名を合わせます。
- 画像は、GitHub の画面の「Add file」→「Upload files」から追加できます。

## 2. 自分のパソコンで確認する(任意)

[Node.js](https://nodejs.org/)(v22.12 以上)が必要です。

```
npm install               # 最初の1回だけ
npm run import-bibtex     # citations.bib を変更したとき
npm run dev               # http://localhost:4321 で確認できます
```

保存すると、ブラウザの表示がすぐに更新されます。止めるときは `Ctrl + C` です。

---

## 3. 公開する(最初の1回だけ)

1. リポジトリ名を `ユーザー名.github.io` にする(公開URLが `https://ユーザー名.github.io/` になります)
2. リポジトリは Public(公開)にする
3. GitHub の Settings → Pages → Source を **GitHub Actions** にする
4. `main` ブランチに保存(push)すると、自動で公開されます(`.github/workflows/deploy.yml`)

## 仕組みのメモ

- 言語の切り替えは、画面右上のボタンで行います。初めて訪れた人には、ブラウザの言語が日本語なら日本語、それ以外は英語で表示されます。
- `src/content/publications/` の `.md` ファイルは、`citations.bib` から自動で作られるものです。直接編集しないでください(Git にも含めていません)。
- 公開時のビルドは `npm run build` で、業績の取り込み → サイトの作成 → 検索用データの作成 の順に行われます。
- 画面上の部品の文言(メニュー、見出し、ボタン)は `src/i18n/ui.ts` にあります。
